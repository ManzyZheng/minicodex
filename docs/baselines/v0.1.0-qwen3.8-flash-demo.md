## 修复前基线

命令：

```powershell
python -m pytest -q
```

结果：

```text
2 failed in 0.19s
exit_code: 1
```

两个缺陷分别为：

1. `total_spending()` 对每笔金额使用 `abs()`，使退款反而增加总支出。
2. `category_totals()` 直接使用原始分类名，导致 `Food`、` food ` 和 `food` 被分为不同类别。

## Agent 修复

Agent 在一次 `edit_file` 调用中完成两项最小修改：

```diff
+def normalize_category(category: str) -> str:
+    return category.strip().lower()

-    return round(sum(abs(expense.amount) for expense in expenses), 2)
+    return round(sum(expense.amount for expense in expenses), 2)

-        totals[expense.category] += expense.amount
+        totals[normalize_category(expense.category)] += expense.amount
```
